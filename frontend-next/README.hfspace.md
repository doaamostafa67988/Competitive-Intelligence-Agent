# Competitive Intelligence & Market Watch Agent — Next.js Dashboard

Set the `NEXT_PUBLIC_API_BASE` **Variable** (Space Settings → Variables) to
your deployed backend Space's `/api/v1` URL **before** the first build —
Next.js bakes `NEXT_PUBLIC_*` values in at build time.
